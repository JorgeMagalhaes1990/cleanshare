# Documentação legacy

Os documentos e ficheiros CleanShare e OutShare preservam decisões e implementação anteriores. Podem ser consultados como histórico, mas não são fonte de verdade para marca, catálogo, seguro, identidade, plano económico ou expansão.

Em particular, não reutilizar:

- o catálogo generalista e o limiar de 300 EUR;
- CMD como requisito exclusivo;
- financiamento de 30% do prémio de seguro pela plataforma;
- cenários de custo e resultados anteriores;
- qualquer texto que apresente Portugal como limite geográfico do projeto.

Os documentos atuais encontram-se nas pastas `docs/strategy`, `docs/insurance`, `docs/legal` e `docs/presentations`.
