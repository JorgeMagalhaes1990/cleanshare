# OutZila

OutZila is a planned protected peer-to-peer marketplace for premium outdoor and leisure equipment. The current web application remains a pilot while the required identity, signature, payment, deposit and insurance integrations are selected and validated.

## Important commercial assumptions

The planning model assumes a 20% marketplace commission, a working insurance premium of 10% of the rental value, and a possible 10% distribution remuneration paid by the insurer to OutZila. The renter pays 100% of the premium. These are planning assumptions only, subject to insurer agreement, pricing and regulation.

The Year 1 target is 1,500 operations in Portugal during the first twelve months after launch. Portugal is the pilot, not the market limit. The priority expansion markets are Spain, France, Germany and Italy.

## Scope of this repository

Documentation defines the intended production model. The code documents and supports the current pilot only. A strategy update does not make a payment, insurance, identity or signature service live.
